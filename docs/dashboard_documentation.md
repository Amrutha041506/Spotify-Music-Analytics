# Power BI Dashboard Documentation

**Status:** no `.pbix` file is included and **no dashboard screenshots exist**. Power BI Desktop is Windows-only and could not be run where this package was
built, and a hand-made or empty `.pbix` would not be genuine. Everything needed to build the report in ~1 hour is provided;
the visual layout below was **not** rendered by the author, so adjust sizes to taste. No screenshots are included.

## Files
| File | Purpose |
|---|---|
| `dashboard/powerbi/data/*.csv` | five tables generated by `python -m src.pipeline` |
| `dashboard/powerbi/load_data.pq` | Power Query (M) for each table, with data types |
| `dashboard/powerbi/data_model.md` | tables, relationships, column settings |
| `dashboard/powerbi/dax_measures.md` | all DAX measures |
| `dashboard/powerbi/spotify_theme.json` | dark/green theme (JSON syntax validated; import not tested in Power BI) |

## Build steps
1. Run the pipeline. 2. Load data with `load_data.pq`. 3. Create relationships (`data_model.md`). 4. Import the theme.
5. Add the measures. 6. Build the three pages below. 7. Save as `Spotify_Music_Analytics.pbix`.
Canvas: 16:9 (1280x720 default). Page background `#121212`, cards `#191414`, accent `#1DB954`, secondary text `#B3B3B3`, font Segoe UI.
Add a title text box at the top-left of every page and turn on *Sync slicers* for Genre, Popularity and Explicit across pages (View > Sync slicers).

## Interactivity checklist
* Slicers filter every visual on the page (except the static correlation matrix).
* Hover tooltips show `Track Rows` and `Avg Popularity`.
* Optional bookmarks: "All data" and "Top 10% popularity" (popularity slicer >= 80).

## Large dataset (~1M rows) tips
* Use Import mode (CSV, ~150 MB for the fact table). Disable *Auto date/time*.
* Prefer `dim_*` columns on axes; hide unused fact columns; avoid slicers on `track_name`.
* The slicer-aware correlation measure iterates rows - use it on one card only.

## Streamlit alternative
`streamlit run dashboard\streamlit_app.py` gives a quick interactive exploration without Power BI.

## What was verified without Power BI
`tests/test_powerbi_assets.py` statically checks that (a) every `table[column]` used in the DAX exists in the exported CSVs,
(b) every measure referenced by another measure is defined, (c) DAX brackets balance and `VAR`s are used, (d) every column
typed in `load_data.pq` exists in its CSV and no fact column is left untyped, (e) relationship key columns exist and the
"one" side is unique, (f) the theme JSON has the required keys and valid colours. These checks do **not** prove the DAX
evaluates correctly or that the M code loads - open the report in Power BI Desktop and compare a few KPI values with
`reports/key_findings.md` (Total Tracks, Avg Popularity, Explicit %).
